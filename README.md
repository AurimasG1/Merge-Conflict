## 📘 Overview

This project is a **responsive multi-page website** built as a team assignment at **TECHIN**.
The interface implemented from a **custom Adobe design file**.

The main objective was to recreate the design as accurately as possible while ensuring:

* functional navigation and interactions
* hover and focus states
* responsive layouts
* accessibility compliance (**WCAG Level AA**)
* clean, structured code
* team collaboration using GitHub

## ✨ Features

### 🔹 Responsive Navigation

* Desktop and mobile navigation
* Accessible mobile menu
* Focus trap inside mobile menu
* Escape key closes menu
* Background scrolling disabled when menu open
* Focus restored when menu closes

### 🔹 Accessibility (WCAG AA)

* Semantic HTML structure
* Keyboard-accessible navigation
* Visible focus states
* Accessible color contrast
* ARIA attributes for menu controls
* Proper heading hierarchy
* Accessible error messages in forms

### 🔹 Contact Form

* Required field validation
* Email format validation (regex)
* Error messages for invalid inputs
* Errors removed while typing
* Prevents submission if fields are invalid

### 🔹 UI/UX

* Hover and focus states
* Responsive layouts (mobile, tablet, desktop)
* Layout implemented according to provided design
* Consistent spacing and typography

## 🧪 Testing & QA

Testing was performed throughout development to ensure functionality, responsiveness, and accessibility.

**Manual testing**

* All navigation links and buttons
* Mobile menu behavior
* Form validation
* Responsive layouts across screen sizes
* Cross-browser checks

**Accessibility testing**

* Keyboard navigation testing
* Focus state verification
* Screen-reader–friendly structure
* WAVE accessibility evaluation tool

**Design accuracy**

* PixelPerfect browser extension used to compare implementation with design
* Layout spacing, typography, and alignment verified against design file

**Tools used**

* **WAVE** – accessibility evaluation
* **PixelPerfect** – design comparison
* **Chalk** – visual feedback and review annotations during QA
* Browser DevTools

The QA team reviewed pages and reported issues for fixes before final submission.
